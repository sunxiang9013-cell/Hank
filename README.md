# Hank

音乐陪练机器人的设计模型、硬件资料及开发备份。

## 文件位置

- 根目录：原始图片、硬件架构图、技术总结、PDF 和模型压缩包。
- `模型/`：机器人模型、舵机图纸与微雪屏幕结构文件，保留原目录结构。
- `Coding/`：开发环境说明与完整备份使用说明。
- [完整开发备份（Releases）](https://github.com/sunxiang9013-cell/Hank/releases/tag/backup-20261005)：原始 `小智双板完整合并备份_20261005.zip`，1,026,578,810 字节。超过普通仓库单文件限制，因此作为附件保存。

## 完整恢复

1. 通过 Code → Download ZIP 下载仓库，或使用 Git 克隆。
2. 从上面的 Releases 页面下载完整开发备份，放入 `Coding/`，并使用原文件名 `小智双板完整合并备份_20261005.zip`。
3. `upload-manifest.json` 记录全部 23 个原始文件的相对路径、大小及 SHA-256，便于核对。额外 README 和清单是上传时添加的说明。
