## 编译

统一脚本：

```powershell
& D:\Espressif\projects\hank-dual-20261005\Build.ps1 -Target all
# 也可使用 -Target audio 或 -Target display
```

或进入环境后使用工程标准命令：

```powershell
Set-Location D:\Espressif\projects\hank-dual-20261005\audio
python scripts/build.py hank-s3-audio --name hank-s3-audio

Set-Location D:\Espressif\projects\hank-dual-20261005\display
idf.py build
```

主控标准脚本会重新生成 sdkconfig；后续配置变更应遵守 audio/AGENTS.md，避免只改生成文件。首次构建后，两套工程所有启用的 CONFIG_* 项均与原始备份一致。
